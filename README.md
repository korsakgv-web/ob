# Обследование — PWA для обследования зданий и сооружений

Приложение для проведения технического обследования зданий и сооружений с возможностью работы в офлайн-режиме, фотофиксации дефектов, формирования отчётов (Excel/Word) и синхронизации через Dropbox.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `index.html` | Чистая HTML-разметка (без inline CSS/JS) |
| `styles.css` | Все стили приложения (вынесены из index.html) |
| `app.js` | Вся логика приложения (вынесены из index.html) |
| `manifest.json` | PWA-манифест (иконки, start_url, scope) |
| `sw.js` | Service Worker с кэшированием и офлайн-режимом |

## Быстрый старт

### Локальный запуск
1. Склонируйте репозиторий
2. Откройте `index.html` в браузере или используйте локальный сервер (например, Live Server в VS Code)
3. Для корректной работы PWA и Service Worker рекомендуется использовать HTTPS или `localhost`

### Деплой на GitHub Pages
1. Загрузите файлы в ветку `gh-pages` или в папку `/ob/` основной ветки
2. Убедитесь, что `manifest.json` и `sw.js` доступны по путям `/ob/manifest.json` и `/ob/sw.js`
3. Service Worker зарегистрируется автоматически при первом посещении

## Основные возможности

- **Осмотр объектов**: создание точек обследования с привязкой к осям (вертикальные и горизонтальные)
- **Фотофиксация**: загрузка фото, сохранение оригиналов в IndexedDB, создание миниатюр, наложение штампов
- **Дефекты**: классификация по категориям (1–5), описание, привязка к точкам
- **Отчёты**: экспорт в Excel (.xlsx) и Word (.docx) — список дефектов, фотоальбом, протокол прочности
- **Офлайн-режим**: Service Worker кэширует статические ресурсы, приложение работает без интернета
- **Синхронизация**: Dropbox OAuth2 для резервного копирования и переноса проектов между устройствами

## PWA-функции

- Установка как мобильного приложения (Add to Home Screen)
- Офлайн-доступ к загруженным ресурсам
- Адаптивный дизайн для мобильных устройств

## Требования

- Современный браузер с поддержкой Service Worker, IndexedDB, Canvas
- Для Dropbox-синхронизации: учётная запись Dropbox и настройка OAuth2

## Разработка

Все стили в `styles.css`, вся логика в `app.js`. HTML-разметка в `index.html` содержит только структуру и ссылки на ресурсы.
